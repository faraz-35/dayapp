# Security Policy

DayApp runs entirely on your Mac and stores everything in a local database.
It makes no network requests on its own. The only exceptions are the optional
in-app update check (GitHub Releases) and optional mobile sync, which talks
straight to a GitHub repo you choose.

## Supported versions

The latest release only.

## Reporting a vulnerability

Open a [private security advisory](
https://github.com/faraz-35/dayapp/security/advisories/new),
or reach me through [faraz-35.vercel.app](https://faraz-35.vercel.app).
Please don't report security problems in public issues.

Include what you found and how to reproduce it. You'll hear back within a few
days.
